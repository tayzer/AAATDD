# Third-party notices for the TADA tool package

The development tool package bundles Gherkin **35.0.0** and Cucumber.Messages **29.0.1**, alongside TADA assemblies. Their versions and hashes are locked in `src/Tada.Core/packages.lock.json` and the CLI lock. The .NET runtime is a separately installed prerequisite, not bundled in the framework-dependent tool package. The Reqnroll/MSTest/MTP/SQLite example dependencies are restored separately and have their own terms; see the retained candidate licence research under `docs/research/`.
